DÚVIDAS

Perguntas frequentes.

O Prancheta precisa de internet para jogar?+

O objetivo do Prancheta é funcionar como jogo desktop. Recursos de atualização ou download podem exigir internet, mas a experiência principal é local.

Onde devo baixar novas versões?+

Sempre use este site oficial: pranchetafc.app.br. Evite instaladores distribuídos por páginas ou links desconhecidos.

O Windows pode mostrar um aviso ao instalar?+

Aplicativos novos ou com pouca reputação de download podem receber alertas do Windows. Confira se o arquivo veio deste domínio antes de continuar.

Como saberei qual versão estou baixando?+

A versão publicada aparece junto ao botão de download. Quando disponível, também exibiremos a identificação do arquivo para conferência.
